# PO Flow

## Phases

1. `po-brainstorming`: clarify the problem and explore options.
2. `po-spec`: define requirements, workflows, edge cases, and constraints.
3. `po-plan`: convert the spec into delivery slices and dependencies.
4. `po-execution`: answer implementation questions and manage scope.
5. `po-review`: verify artifact and release readiness.
6. `po-ship`: prepare release, handoff, and post-ship memory.

## Supporting Skills

- `docs`: save and index artifacts.
- `memories`: read and write durable product context.
- `prd`, `user-story`, `uat`, `change`, `knowledge`: create or operate on specific artifacts.
