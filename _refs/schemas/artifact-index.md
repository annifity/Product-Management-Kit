# Artifact Index Schema

| Field | Meaning |
|---|---|
| Artifact | Human-readable artifact name |
| Type | BRD, PRD, spec, story, UAT, decision, evidence, changelog, release, roadmap, traceability, risk, initiative-state |
| Status | Draft, reviewed, baselined, shipped |
| Updated | Last update date |
| Path | Workspace-relative path |
| Source | Source artifact, ticket, or session |
