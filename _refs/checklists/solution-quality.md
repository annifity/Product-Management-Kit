# Solution Quality Checklist

Use when comparing or reviewing solution options.

- Problem fit: the option solves the validated problem, not only the visible symptom.
- Simplicity: choose the least complex approach that satisfies the requirement.
- Configurability: favor behavior that can be adjusted without code when rules are volatile.
- Reuse: prefer reusable patterns or components when reuse is likely and cheap.
- Operational manageability: support, ops, and monitoring needs are realistic.
- Failure handling: partial failure, rollback, retry, timeout, and manual override are defined.
- Security and permission behavior are explicit.
- Data integrity and audit needs are clear.
- Trade-offs are named; do not say "best balance" without what is being given up.
- Riskiest assumptions are identified with the cheapest validation method.
