# Stakeholder Governance Checklist

Use when a decision, scope movement, risk acceptance, launch, or prioritization choice needs accountable ownership.

## Decision Rights

- Decision maker is named.
- Approver is named when different from decision maker.
- Consulted stakeholders are listed.
- Informed stakeholders are listed.
- Escalation path is clear.
- Decision SLA or deadline is explicit.

## Decision Record

Capture the following for material decisions:

| Field | Value |
|---|---|
| Decision | [Decision statement] |
| Options considered | [Options] |
| Chosen option | [Option] |
| Why | [Rationale] |
| Evidence | [Evidence or assumption quality] |
| Trade-offs | [Trade-offs] |
| Risks accepted | [Risks] |
| Owner | [Owner] |
| Accepted by | [Name] |
| Accepted date | [Date] |
| Review date | [Date or trigger] |

## Conflict Handling

- Separate factual disagreement from priority disagreement.
- Record assumptions when evidence is missing.
- Name who can break ties.
- Use "disagree and commit" only with an explicit owner and review point.
- Do not hide unresolved stakeholder conflict inside neutral prose.
