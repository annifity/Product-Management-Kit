# Experiment Design

Use when the team needs evidence before committing product scope.

1. Write the hypothesis in a falsifiable form.
2. Name the product decision the experiment will inform.
3. Choose the method with the lightest cost that can answer the decision.
4. Define participants, sample logic, and recruitment source.
5. Define success metrics, guardrails, and event tracking.
6. Set decision criteria before results are collected.
7. Capture ethical, privacy, compliance, or consent risks.
8. Record results in an evidence ledger and move to `validate`.

## Method Guide

| Method | Use When |
|---|---|
| Prototype test | Interaction, comprehension, or desirability is uncertain. |
| Concierge test | Value can be delivered manually before automation. |
| Interview round | Motivation, jobs, language, or workflow context is unclear. |
| Survey | Directional preference or segmentation needs a broader signal. |
| Analytics review | Existing behavior can answer the question. |
| A/B or beta | Live product behavior and measurable outcomes are available. |
