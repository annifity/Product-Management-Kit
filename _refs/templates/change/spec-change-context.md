# Spec Change Context Block

Use this block when a requirement changes during implementation and developers or AI coding tools need exact context.

```text
SPEC CHANGE - [Version] ([Sprint/Date])

Change type      : Minor / Material / Breaking
Decision         : Accepted / Rejected
Decision owner   : [Owner]
Affected tickets : [Jira keys]
Affected docs    : [PRD/Spec/Story/UAT links]

Delta:
- [What changed]
- [What did not change]

Roadmap impact:
- [No change / sequencing changed / scope moved]

Implementation guidance:
- [Specific developer context]

Acceptance impact:
- [AC added/modified/removed]

UAT impact:
- [Tests added/modified/removed]
```
