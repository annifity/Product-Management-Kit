# PRD from PRO + Client Feedback

Use this when Prototype First Workflow has produced PRO, runnable prototype behavior, and feedback or learning. The PRD must distinguish what was validated, what changed after feedback, what remains assumption, and what is ready for delivery specification.

## 1. Background

- Link or summarize the PRO.
- Prototype version or demo reference when available.

## 2. Validated Problem

- Problem confirmed by prototype feedback.
- Evidence or feedback supporting it.

## 3. Target Users

- User segments that remain valid.
- User segments changed after feedback.

- Goals after learning from the prototype.
