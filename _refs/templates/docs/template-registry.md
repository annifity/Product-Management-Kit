# Template Registry

Use to record reusable templates preferred by a team or project.

| Template ID | Type | Name | Path | Applies To | Status |
|---|---|---|---|---|---|
| TPL-001 | PRD / BRD / Story / UAT / Release | [Name] | [Path] | [Project/Team] | Active |

## Selection Rules

- Use a project-specific template when one exists and matches the requested artifact.
- Use the Annifity default template when no project-specific template is known.
- Verify required sections before saving a new template.
- Store durable template preference in `memories`.
