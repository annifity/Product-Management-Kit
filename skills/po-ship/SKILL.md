# PO Ship

Use this when the team is preparing to release, hand off, or publish final product documentation.

## Process

1. Read final PRD/spec/stories/UAT and latest decisions.
2. Verify readiness using the release checklist.
3. Produce the ship package the user needs.
4. Ask `docs` to export/index final artifacts.
5. Ask `memories` to save lessons learned and final decisions.

## Output

- Release readiness verdict
- Open blockers
- Final artifact list
- Release note
- Stakeholder summary
- UAT signoff summary
- Post-ship memory updates
