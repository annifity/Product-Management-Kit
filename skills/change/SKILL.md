# Change

Use this for controlled product requirement changes.

## Process

1. Identify the current baseline artifact.
2. Clarify the requested change.
3. Assess impact on scope, stories, UAT, timeline, dependencies, risk, and release.
4. Draft a change plan and ask for confirmation before applying edits.
5. Apply changes consistently across affected artifacts.
6. Ask `docs` to update changelog and decision logs.
7. Ask `memories` to persist durable decisions.
